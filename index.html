    What the automated tests verify

    • ①No duplicate counting
      The same number in any format counts once; the earliest sign-up keeps the credit.
    • ②Correct referral attribution
      Only real codes are credited; unknown codes count as direct.
    • ③Notifications only at milestones
      25%, 50%, 75% and 100% of each target, never twice.
    • ④Accurate rewards
      Paid only at the full target; approvals can’t pass the budget.
